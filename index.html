Milestone

From bad models to
shipping systems.

I started coding in 2022 with no mentor, no budget, and access to only the worst AI models. Every project took months because I wasn't just learning to code — I was learning how to make bad AI produce good systems. That forced me to debug, re-architect, and rebuild constantly.

By 2025, I had rebuilt my main product (YoTop10, a top-10 listings platform) 5 times. Not because the code failed, but because my ability to engineer AI output was finally catching up to my vision. Each version got faster, cleaner, closer to what I wanted.

Today, I have four flagship products:

YoTop10 v6 — rebuilt from scratch on Node, Next.js, MongoDB. Nearly complete. Until it ships, a static v1 rebuild is running to build domain authority.
Ecosystem — Portfolio, Blog, and Store all live. A unified digital presence.
Minitia — a 25-tool developer suite. First tool (BugSwarm, a bug finder) near completion.
Moistello — a rotating savings and credit app on the Stellar blockchain.

I run multiple static blogs (tipshub.cc, proptengine.cc, cremy.co, acad.ngentech.co) to build domain authority while the core products reach full production. Not all are on their live servers yet. All have domains. All are deliberate.
